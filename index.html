Arka Labs Analytics

Arka Labs Analytics is a personal, read-only tool built for the owner of the YouTube channel Arka Labs (@arkalabs). It reads the channel's own statistics through Google's official YouTube APIs (YouTube Data API, YouTube Analytics API and YouTube Reporting API) and shows them in a simple morning dashboard.

What it does

  • Reads channel and video statistics: views, watch time, subscribers gained and lost, average view duration, audience retention, traffic sources and search terms.
  • Read-only by design: it cannot upload, edit, delete or publish videos, and it cannot post comments.
  • It only ever accesses the owner's own channel.

Who it is for

This is a single-user application. The only user is the owner of the Arka Labs YouTube channel.
